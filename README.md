# Mindful Search — GitHub Pages + Google Forms

This version is a static website for GitHub Pages. Feedback is submitted directly to Google Forms/Google Sheets.

## Feedback setup
The site is already configured with the provided Google Form and these entry IDs:
- Rating: entry.1907288098
- Feedback: entry.2145460381

The website submits to the Google Forms `formResponse` endpoint using a URL-encoded POST, so users do not need to open the Google Form separately.

## Publish with GitHub Pages
1. Upload `index.html`, `styles.css`, and `app.js` to a GitHub repository.
2. Go to Settings → Pages.
3. Deploy from the `main` branch and `/ (root)`.
4. Open the generated `https://USERNAME.github.io/REPOSITORY/` URL.
